# Vulnerable Audit Repo (for security testing)

This repo contains intentionally insecure frontend and backend code for security audits and training. Run only in isolated environments.

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run locally:

```bash
npm start
```

3. Open the frontend at `http://localhost:3000/frontend/index.html` (or use a static file server).

Safety:
- Run inside a VM or isolated network.
- Do not expose ports to the public internet.
